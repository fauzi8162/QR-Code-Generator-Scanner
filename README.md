# ⚡QR STUDIO
Live Demo : https://fauzi8162.github.io/QR-Code-Generator-Scanner/

**QR STUDIO** adalah aplikasi berbasis web *all-in-one* untuk membuat (*generate*) dan memindai (*scan*) QR Code dengan antarmuka **Neo-Brutalism** yang berani dan responsif.

---

## 🚀 Fitur Unggulan

### 🎨 QR Generator
Membuat berbagai tipe QR Code secara instan:
- **Teks & URL**: Untuk pesan biasa atau tautan website.
- **WiFi**: Memudahkan tamu terhubung ke jaringan tanpa mengetik password.
- **WhatsApp**: Chat langsung ke nomor tujuan dengan pesan otomatis.
- **Telepon**: Membuka dialer telepon secara otomatis.
- **Smart Maps**: Secara otomatis mengekstrak koordinat dari link Google Maps yang ditempel.

### 🔍 QR Scanner
Fleksibilitas dalam membaca data QR Code:
- **Live Camera**: Menggunakan kamera perangkat untuk scanning real-time.
- **File Upload**: Membaca data dari file gambar (PNG/JPG) yang diunggah.
- **Smart Action**: Tombol salin teks dan deteksi otomatis link URL.

---

## 🛠️ Teknologi

Aplikasi ini dibangun menggunakan teknologi *client-side* murni:
* **Tailwind CSS**: Untuk desain Neo-Brutalism.
* **QRCode.js**: Library untuk pembuatan QR Code.
* **Html5-QRCode**: Library untuk pemindaian QR melalui browser.
